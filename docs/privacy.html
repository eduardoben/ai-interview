1. Overview & Core Privacy Guarantee

AI Interview Assistant is designed as a privacy-first, fully local on-device AI rehearsal tool for interview preparation and practice.

  • Zero Cloud Transmission: Speech-to-text transcription, question detection, and generative language model inference execute 100% locally on your device hardware (NPU, GPU, or CPU).
  • Zero Voice/Biometric Retention: Audio captured via your microphone is buffered ephemerally in volatile system RAM only while speech is active and is discarded immediately after acoustic processing. We never store, serialize, or transmit audio files or acoustic waveforms.
  • Zero Developer Telemetry: We do not track, collect, monetize, sell, or transmit personal data, interview questions, answers, usage statistics, or telemetry.

2. Information We Process & How It Is Handled

A. Microphone Audio (android.permission.RECORD_AUDIO)

Used strictly for real-time speech-to-text recognition during active rehearsal sessions to detect questions and display assistive talking points. Audio is processed ephemerally in volatile RAM and immediately overwritten.

Before audio capture begins, the Application presents a prominent disclosure requiring explicit acknowledgment of applicable local recording consent and two-party wiretapping laws.

B. Local Session History & Transcripts

Stored exclusively in a sandboxed local Android SQLite database (interview_assistant.db) within your device's private application storage. Explicit Android Auto Backup rules exclude all database files, preferences, and downloaded model weights from Google Cloud and device-to-device transfers.

C. Downloaded AI Pipeline Model Weights

Model weights are downloaded directly over encrypted HTTPS from Hugging Face (huggingface.co / hf.co). All downloads are cryptographically verified via streaming SHA-256 checksums and exact byte size validation.

D. User-Initiated Support & Feedback (Optional)

The Application includes an optional "Send Feedback" feature. Feedback is never transmitted automatically or in the background. When triggered, the Application opens your device's native email or sharing client addressed to feedback@aiinterviewassistant.app, giving you complete visibility and control to review, edit, or delete any text before sending.

You may optionally check boxes to attach on-device diagnostic metadata (hardware profile, model verification status, recent process logs) and/or session transcripts. These options are disabled (unchecked) by default and are used strictly to resolve technical inquiries without third-party sharing.

3. In-App Data Deletion & Storage Management Rights

  • Purge Interview History: Navigate to Activity and select "Clear All History" to permanently delete all stored interview questions and answers.
  • Purge Downloaded AI Models: Navigate to System & Diagnostics and select "Purge Downloaded AI Models" to permanently delete all on-device neural network weights (~3.1 GB) and reclaim storage.
  • Application Uninstallation: Uninstalling the Application through Android OS settings immediately and irreversibly destroys all databases and local model files.

4. Children's Privacy

The Application is targeted exclusively at adults aged 18 and older preparing for professional, collegiate, or technical job interviews. We do not knowingly target, collect, or solicit information from children under the age of 13.

5. Security & Network Protections

  • Strict HTTPS Enforcement: The Application declares a system-level Network Security Configuration prohibiting cleartext HTTP traffic globally.
  • No Dynamic Code Loading: The Application never downloads executable code or uses dynamic class loading.
  • Release Log Stripping: Debug and informational logging is permanently stripped from production release builds.
